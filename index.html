FISI 711 - Teoria Quântica I, Lista IV, Problema 10

Esse programa em HTML permite visualizar os harmônicos esféricos e comparar as densidades de probabilidade radiais dos potenciais do átomo de hidrogênio e o poço esférico infinito de raio $a$, dado por
$$V(r) = \left\{\begin{array}{c}0 \textrm{, se } r < a\\ \infty\textrm{, se } r \geq a\end{array}\right.\, .$$

Clique em um dos botões abaixo para selecionar o item do problema:

Harmônicos esféricos $\big|\textrm{Y}_{\ell}^{m}(\theta, \phi)\big|$ na esfera unitária

Para movimentar a esfera, arraste-a com cursor (ou dedo). Os eixos cartesianos estão representados por vermelho para o eixo $x$, verde para o eixo $y$ e azul para o eixo $z$.

Densidade de probabilidade radial $\textrm{P}_{nl}(r) = r^2\big|\textrm{R}_{nl}(r)\big|^2$

Discussão (item b)

  • Nós radiais. Poço: Pnl tem n − 1 nós em 0 < r < a, qualquer que seja l (o n-ésimo zero de jl é a própria parede r = a). Hidrogênio: n − l − 1 nós.
  • Alturas dos máximos. Poço com l = 0: todos os lóbulos têm a mesma altura (P = 2 sen²(nπr/a)/a). Para l > 0 os lóbulos internos são um pouco menores (barreira centrífuga) e as alturas tendem a se igualar para fora. Hidrogênio: o lóbulo mais externo é o maior e os internos são bem menores; o último máximo fica perto de r ≈ n²a0 (exato para l = n−1), então os máximos ficam mais baixos e largos quando n cresce.
  • Espaçamento entre nós. Poço: aproximadamente uniforme (V = 0 dentro do poço; Δr ≈ πa/xnl, exatamente a/n para l = 0). Hidrogênio: cresce com r, pois E − V(r) = −1/(2n²) + 1/r diminui para fora e o comprimento de onda local aumenta; os nós se concentram perto do núcleo.
  • Degenerescência em l. Hidrogênio: sim, En = −13,6 eV/n² não depende de l (degenerescência “acidental” do potencial 1/r, ligada ao vetor de Runge–Lenz). Poço: não, Enl = xnl² ħ²/(2ma²) depende de l; só resta a degenerescência 2l + 1 em m (veja as tabelas acima).
  • Por que Pnl não depende de m. Em um potencial central, a equação radial contém só l(l+1)/r² (barreira centrífuga), logo Rnl não depende de m; além disso ∫|Ylm|² dΩ = 1 elimina a parte angular de Pnl. A independência de m reflete a simetria rotacional (degenerescência 2l + 1).
