# Quantum Science, "Q-Science", por Jimi.

Personal website dedicated to theoretical physics, research, and science communication.

[Q-Science](https://bonn3r.github.io/qscience) é o meu site pessoal para divulgar trabalhos acadêmicos em geral e divulgação científica. O site foi construído com base no modelo [Editorial](https://html5up.net/editorial), [Halcyonic](https://html5up.net/halcyonic) e [Verti](https://html5up.net/verti) do criador [HTML5 UP](https://html5up.net), eu optei por não usar soluções como [Hugo](https://gohugo.io/documentation/) ou similares para brincar com programação HTML, CSS e JavaScript. Equivalente ao professor Utônio, eu misturei os ingredientes certos aos elemento X (eu). 

Eu estruturei o site de maneira que a página inicial identifica o idioma do seu navegador e direciona para o idioma equivalente. Até o momento eu só escrevo em inglês e português. No futuro, caso escreva em algum outro idioma (ou as IA traduzam para mim), eu desponibilizarei o máximo possível.



## **1.** Estrutura de arquivos

A primeira e mais importante mudança é na estrutura de arquivos para suporte de multiplos idiomas com cada idioma guardado em uma página específica e um arquivo `index.html` na pasta principal encaminha o leitor para a página com seu idioma específico.

### **1.1** Estrutura das pastas

As pastas de arquivos são organizadas da seguinte forma:



<ul>📁 qscience
	<ul>
		<li>📁 assets</li>
		<li>📁 br</li>
			<ul>
				<li> ⁝ Pastas de arquivos em português brasileiro </li>
			</ul>
		<li>📁 en</li>
			<ul>
				<li> ⁝ Pastas de arquivos em inglês </li>
			</ul>
		<li>📁 <em>outro idioma aqui</em> </li>
			<ul>
				<li> ⁝ Outros idiomas seguirão a mesma lógica </li>
			</ul>
		<li>📄 index.html</li>
		<li>🔑 LICENSE.txt</li>
		<li>ℹ️ README.md</li>
	</ul>
</ul>

Seguindo essa estrutura, posso construir o site idefinidamente e mante-lo organizado.
