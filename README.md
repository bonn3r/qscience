# Q-Science, por Willian Bonner.

[Q-Science](https://bonn3r.github.io/qscience) é o meu site pessoal para divulgar trabalhos acadêmicos em geral e divulgação científica. O site foi construído com base no modelo [Editorial](https://html5up.net/editorial) do criador [HTML5 UP](https://html5up.net), eu optei por não usar soluções como [Hugo](https://gohugo.io/documentation/) ou similares para brincar com programação HTML, CSS e JavaScript. Eu alterei profundamente o modelo original e organizei as modificações aqui no README. Caso alguém algum dia queira ver e aprender com o que fiz, sinta-se a vontade.

O README original está disponível no fim dessa descrição.

## **1.** Estrutura de arquivos

A primeira e mais importante mudança é na estrutura de arquivos para suporte de multiplos idiomas com cada idioma guardado em uma página específica e um arquivo `index.html` na pasta principal encaminha o leitor para a página com seu idioma específico.
