Fonte Principal

Este site foi construído a partir do template Editorial, criado por AJ e disponibilizado em html5up.net. Também utilizei como principal ferramenta o chatbot DeepSeek.

Construí o site desmembrando o arquivo CSS principal do template Editorial em pequenos códigos para que pudesse compreender o funcionamento do site e para que pudesse criar meus próprios arquivos CSS compatíveis com o site.

Os arquivos criados por mim foram:

Pastas

  • 📁 assets - pasta que organiza todos os elementos utilizado para construção e configuração do site.
  • 📁 scr - pasta que contém os arquivos HTML que são "chamados" nas páginas principais.
  • 📁 br e 📁 en - pastas que contém os arquivos HTML das páginas em português e inglês, respectivamente.

Arquivos JavaScritp

  • 📄 ensidebar.js e 📄 sidebar.js - Controle do menu lateral.
  • 📄 gaveta.js - Controle das gavetas dos resumo e referência latex dos artigos disponibilizados.
  • 📄 language.js - Controle da troca de idioma e redirecionamento automático inicial para o site com mesmo idioma do navegador.
  • 📄 theme.js - Controle da troca "claro e escuro"

Arquivos CSS

  • 📄 captcha.css - Configura o recaptcha (em desuso).
  • 📄 gaveta.css - Configura as gavetas e botões nos artigos disponibilizados.
  • 📄 sidebar.css - Configuração da aparência da barra lateral.
  • 📄 theme.css - Configuração das cores.

Todos os demais arquivos em códigos, mesmo que não estejam presente no projeto original, são derivados diretamente dele com pequenas alterações.

Os demais itens utilizados foram:

  • Software Inkscape para edição e geração de imagens nos formatos PNG e SVG.
  • Imagens de uso livre do repositório SVG REPO.
  • A ferramenta HTML Color Codes para conferir os códigos hexadecimais das cores, compatibilidade entre cores e tons de cores.
